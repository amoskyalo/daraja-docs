# Terminologies

Understanding these key terms will help you navigate the M-Pesa API ecosystem effectively.

## Core Services

<Highlight>M-PESA:</Highlight> It is a mobile money transfer service in Kenya that allows users to store and transfer
money through their mobile phones.

<Highlight>Command IDs:</Highlight> This is a unique command that specifies transaction types.

## Payment Types

<Highlight>Salary Payment:</Highlight> This supports sending money to both registered and unregistered M-Pesa customers.

<Highlight>Business Payment:</Highlight> This is a normal business to customer payment, supports only M-Pesa registered
customers.

<Highlight>Promotion Payment:</Highlight> This is a promotional payment to customers. The M-Pesa notification message is
a congratulatory message. Supports only M-Pesa registered customers.

## Account Types

<Highlight>Short Code:</Highlight> A short code is the unique number that is allocated to a pay bill or buy goods
organization through they will be able to receive customer payment. It could be a Pay bill, Buy Goods or Till Number.

<Highlight>Pay Bill:</Highlight> It is a cash collection service that allows your organization to collect money on a
regular basis from your customers through M-PESA.

<Highlight>Buy Goods:</Highlight> It is mostly for retail purchase of goods and services. Both parties immediately
confirm these proximity payments via text message. No relationship between the buyer and the organization or account
number is required.

<Highlight>Till Number:</Highlight> Till number is attached to the store number. This is used to make payments by
customers.

## Technical Terms

<Highlight>REST:</Highlight> Representational state transfer is a software architectural style that defines a set of
constraints to be used for creating Web services. Web services that conform to the REST architectural style, called
RESTful Web services, provide interoperability between computer systems on the Internet.

<Highlight>APIs:</Highlight> A set of functions and procedures allowing the creation of applications that access the
features or data of an operating system, application, or other service.

<Highlight>DOCS:</Highlight> Documentation is a technical content deliverable, containing instructions about how to
effectively use and integrate with an API.
